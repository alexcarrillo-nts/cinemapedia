## 🎓 QUÉ ENTENDERÁS

Después de leer estas guías, entenderás:

### Arquitectura
- ✅ Clean Architecture (3 capas: domain, infrastructure, presentation)
- ✅ SOLID Principles (especialmente Dependency Inversion)
- ✅ Cómo las capas se comunican
- ✅ Por qué se hace así

### Riverpod
- ✅ Provider (valores inmutables)
- ✅ StateNotifierProvider (estado mutable)
- ✅ .read() vs .watch()
- ✅ Cómo redibujar widgets automáticamente

### Flujo de Datos
- ✅ Desde que el usuario toca un botón hasta que ve datos en pantalla
- ✅ Cómo los datos van de API → JSON → Entidad → UI
- ✅ Paginación (carga más cuando scrolleas)
- ✅ Caché (no descarga dos veces lo mismo)

### Patrones de Diseño
- ✅ Adapter Pattern (repositorio)
- ✅ Mapper Pattern (conversión de datos)
- ✅ State Notifier (gestión de estado)
- ✅ Pattern Delegation (repository → datasource)

## 💡 TIPS PARA APRENDER MEJOR

1. **Lee comentarios en el idioma que prefieras**
   - Los comentarios están en español (puedo cambiarlos si prefieres)

2. **Usa breakpoints mientras lees**
   - Pon un breakpoint en HomeView.dart
   - Ejecuta en debug
   - Paso a paso mientras lees comentarios
   - Verás el flujo en tiempo real

3. **Dibuja diagramas tú mismo**
   - Después de cada sección, intenta dibujar sin mirar
   - Compara con los diagramas ASCII de las guías

4. **Explica en voz alta**
   - Cubre la pantalla
   - Intenta explicar qué hace cada clase
   - Descubre qué no entiendes aún

5. **Modifica el código**
   - Cambios pequeños: colores, textos
   - Cambios medianos: agregar un campo a Movie
   - Cambios grandes: nueva pantalla completa
   - Verás cómo fallará(guías te ayudan a entender por qué)
