## 🔧 Configuración Inicial

### 1. Asegúrate de tener la API key

```bash
# Crea o verifica que exista:
.env

# Debe contener:
THE_MOVIEDB_KEY=tu_api_key_aqui
```

### 2. Instala dependencias

```bash
flutter pub get
```

### 3. Corre la app

```bash
flutter run
```
